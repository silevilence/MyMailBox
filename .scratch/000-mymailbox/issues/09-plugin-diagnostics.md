## What to build

插件按账户、邮件内容、发送/删除、文件和网络声明所需能力；用户能查看授予范围与故障。

本任务应交付可独立演示或验证的完整行为，包含所需数据、服务、UI、插件接入和错误处理；技术路线及通用完成标准见父规格。

## Acceptance criteria

- [x] 通过宿主入口阻止未获授权操作，说明同进程可信插件并非恶意代码安全沙箱。
- [x] 异常插件与依赖停用可见，导出诊断默认不包含密码、token 和正文。
- [x] 日志包含实例、操作和错误关联 ID，可追踪失败且有大小/保留上限。
