## What to build

在统一 UI 中使用公司账户发送、回复、保存草稿、改状态和同邮箱移动。

本任务应交付可独立演示或验证的完整行为，包含所需数据、服务、UI、插件接入和错误处理；技术路线及通用完成标准见父规格。

## Acceptance criteria

- [ ] 以真实公司测试账户验收发送身份、附件、已发送副本和权限拒绝。
- [ ] 不支持的目录权限/操作显示原因；操作失败不使其他账户失效。
- [ ] 发送结果不确定时复用发件箱对账机制，不盲目重复发送。
