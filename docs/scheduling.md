# 提醒与调度

提醒属于普通插件 `reminders`，调度通过 IReminderService，通知通过 INotificationSink；测试可注入 TimeProvider 和替代通知实现。关闭插件会停止并排空检查循环。GUI 完全退出、关机或插件未启用期间不执行，重新运行后对已到期一次性事项补提醒一次，不虚构退出后的执行记录。

一次性事项保存 UTC 到期瞬间和用户选定的时区 ID，主机时区改变不会改变计划。输入时区内的夏令时不存在时刻和重复时刻会拒绝，并提示选择存在的时刻或使用 UTC 明确指定。关联邮件使用稳定 ID，移动后显示当前位置，关闭邮箱提示原文保留，删除后显示引用不可用。

调度在事务中把到期事项转为已到期并创建唯一投递标识的 outbox。通知存储按标识幂等写入，只有第一次写入且选择横幅时提示。投递结果确认失败可重试，已出现的提示不会重复弹出；投递失败显示在提醒记录中。关闭和取消记录保留，延后增加投递代次。静默模式只在提醒列表记录。横幅只显示用户填写的提醒内容，不附带邮件正文。

每次检查最多领取 100 个到期事项，当前默认每秒检查。循环策略、通用执行重试与并发策略分别由后续工单 70–72 扩展；当前一次性提醒实现不能据此视为完整自动化调度已完成。

## 循环计划

循环计划当前执行提醒动作，规则和执行记录保存在 schedules / schedule_runs。支持固定分钟/小时/24 小时间隔、完成后间隔、每 N 天、每 N 周多日、每 N 月日期/月末/第 N 或最后一个周几、每 N 年固定日期。开始时刻作为持久周期锚点；暂停再启用保留锚点，从下一个符合规则的时刻继续。预览未来 10 次；完成后间隔只能按立即完成估算，实际下一次从通知投递完成时刻加间隔。

日期不存在时显式选择跳过或调整为当月最后有效日期/相同周几。日期范围包含端点，日运行窗口为同日闭区间，排除日按计划时区解释。日历经 IWorkCalendar 替换；内置“周一至周五”不声称包含法定节假日或调休。固定间隔保持 UTC 时长，固定日历时刻保持指定时区的墙上时间。缺失时刻默认跳过、重复时刻默认较早一次。周期规划器与执行器共用规则，通知投递及推进下一次执行在持久记录中可查。

循环提醒恢复默认补一次并推进到当前时间之后，不无限补跑；下述执行策略可配置。

## CRON 与时区

固定使用 [Cronos 0.13.0](https://www.nuget.org/packages/Cronos/0.13.0) 的五字段方言：分、时、日、月、星期；不接受秒、年份、@别名或 H 抖动。支持列表、范围、步长及 L/W/#，周日为 0 或 7。日和星期同时受限时按 AND 匹配，区别于部分 Unix CRON 的 OR；依据 [上游兼容说明](https://github.com/HangfireIO/Cronos#compatibility)。该库只解析表达式和寻找候选，持久调度仍由项目执行器负责。

先枚举本地墙上时间，再经共享解析器应用项目的 DST 策略。缺失时刻可跳过或移至首个有效分钟，重复时刻可仅选择较早或较晚一次，默认分别为跳过和较早。窗口/排除日也在计划时区判断。固定间隔保持 UTC 时长，不套用墙上时间的跳过策略。预览同时显示计划时区时间与 UTC；规则存储明确时区 ID，不随主机时区改变。

## 恢复与执行控制

- 错过策略：迟到超过容忍时间后，可跳过、补一次或最多补 N 次。从允许恢复窗口内最早未执行时刻开始，剩余过期时刻跳过并推进到未来；队列等待超过恢复窗口也跳过。默认容忍 5 秒、恢复窗口 24 小时、补一次。
- 重叠策略：跳过会记录被跳过的到期项；排队每计划仅一个在途执行，按到期顺序领取可执行项，退避中的失败不阻塞其他已到期项；互斥按组名保证跨计划串行，空组名只约束本计划；并发有每计划上限 1–8。队列有持久上限，全局最多 32 个在途执行。
- 每次逻辑执行以计划 ID 和应执行 UTC 时刻唯一标识。SQLite 事务同时创建执行记录、推进下一次运行并领取任务；领取记录包含拥有者和过期时间。正常重启不重复领取有效租约；真正中断后等待租约过期，再按退避恢复。通知仍使用同一投递 ID 幂等去重。
- 超时、尝试次数、重试时刻、取消及错误全部持久保存。首次等待按配置，后续指数增长，最长 1 小时；重试次数不含首次。取消在途操作后等待提供者释放，再解除互斥。提供者必须遵守取消契约；运行程序不会伪造对方已经终止。
- 固定/日历周期在排队时推进下一时刻；完成后间隔在本次最终成功、失败或超时结束后重新计时。重试期间不新建同一完成后计划的下一次执行。周期结束时仍执行最后一个已排队事项，再结束计划。
- 正常退出会取消并排空检查循环，把未确认工作保留为待恢复；完全退出后不运行。测试包含虚拟时钟跳变、模拟断网、真实子进程被杀与租约恢复，未将这些测试称为真实协议验收。

循环页面“执行记录与取消”可查看最近 200 次执行、尝试次数、重试时刻和失败原因，也可取消指定执行；暂停计划会取消排队和在途执行，保留规则。上述为调度层历史，不替代后续自动化步骤历史工单 78。
