# 提醒与调度

提醒属于普通插件 `reminders`，调度通过 IReminderService，通知通过 INotificationSink；测试可注入 TimeProvider 和替代通知实现。关闭插件会停止并排空检查循环。GUI 完全退出、关机或插件未启用期间不执行，重新运行后对已到期一次性事项补提醒一次，不虚构退出后的执行记录。

一次性事项保存 UTC 到期瞬间和用户选定的时区 ID，主机时区改变不会改变计划。输入时区内的夏令时不存在时刻和重复时刻会拒绝，并提示选择存在的时刻或使用 UTC 明确指定。关联邮件使用稳定 ID，移动后显示当前位置，关闭邮箱提示原文保留，删除后显示引用不可用。

调度在事务中把到期事项转为已到期并创建唯一投递标识的 outbox。通知存储按标识幂等写入，只有第一次写入且选择横幅时提示。投递结果确认失败可重试，已出现的提示不会重复弹出；投递失败显示在提醒记录中。关闭和取消记录保留，延后增加投递代次。静默模式只在提醒列表记录。横幅只显示用户填写的提醒内容，不附带邮件正文。

每次检查最多领取 100 个到期事项，当前默认每秒检查。循环策略、通用执行重试与并发策略分别由后续工单 70–72 扩展；当前一次性提醒实现不能据此视为完整自动化调度已完成。

## 循环计划

循环计划当前执行提醒动作，规则和执行记录保存在 schedules / schedule_runs。支持固定分钟/小时/24 小时间隔、完成后间隔、每 N 天、每 N 周多日、每 N 月日期/月末/第 N 或最后一个周几、每 N 年固定日期。开始时刻作为持久周期锚点；暂停再启用保留锚点，从下一个符合规则的时刻继续。预览未来 10 次；完成后间隔只能按立即完成估算，实际下一次从通知投递完成时刻加间隔。

日期不存在时显式选择跳过或调整为当月最后有效日期/相同周几。日期范围包含端点，日运行窗口为同日闭区间，排除日按计划时区解释。日历经 IWorkCalendar 替换；内置“周一至周五”不声称包含法定节假日或调休。固定间隔保持 UTC 时长，固定日历时刻保持指定时区的墙上时间。缺失时刻默认跳过、重复时刻默认较早一次。周期规划器与执行器共用规则，通知投递及推进下一次执行在持久记录中可查。

当前循环提醒恢复默认补一次并推进到当前时间之后，不无限补跑；可配置的补跑、重叠、超时与重试策略仍由 72 实现。
