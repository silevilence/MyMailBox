## 复验入口

- `./scripts/verify.ps1` 执行锁定还原、解决方案构建、示例插件打包、默认非 UI 检查及 win-x64 框架依赖发布。发布检查包含 PST 读取器、运行时配置、MimeKit.Core 和许可文件。构建与验收复用本地依赖、PST、Java、GreenMail 及 NSIS。
- `dotnet run --project tests/MyMailBox.Checks --no-build -- pst-import pst-resume pst-fidelity` 复用 `artifacts/outlook-acceptance/final`。独立探测器回归入口为 `python scripts/check-pst-fixtures.py`。实际结果保存在 `artifacts/task000-pst.log` 和 `artifacts/task000-pst-regression.log`。
- `protocol-live protocol-faults` 检查使用本机 GreenMail 和套接字故障服务器。结果见 `artifacts/task000-live.log`。验收结束后已关闭本轮启动的 GreenMail。
- `./scripts/inspect-outlook-rules.ps1 -SelfTest` 可离线重跑规则判定。Windows PowerShell 5.1 的脚本执行策略阻止了本机复验。
