# 办公邮箱界面改版

## 日常操作

| 要做的事 | 改版后的操作 |
| --- | --- |
| 收信、读信 | 启动后进入收件箱。可以查看全部账户，也可以指定账户。选中邮件就能阅读已下载的正文，查看原邮件时可以保存附件。 |
| 找邮件 | 在收件箱右上角输入主题并按回车，或打开侧栏的“搜索邮件”设置更多条件。 |
| 写信和接着写 | “写邮件”新建一封空白邮件。“草稿箱”列出各账户的草稿，选中后点“继续写”。已发送的本地副本和等待投递的邮件分别位于“已发送”和“发件箱”。 |
| 启停插件 | 打开“设置”中的“插件管理”。选中插件即可查看版本、状态和权限。普通插件可立即启用或停用，有依赖时会在变更前提示。个别使用自定义窗口的插件停用后，窗口和功能立即关闭，设置保存。若窗口组件仍被占用，软件会提示重启后再启用或卸载，其他插件仍可操作。 |
| 整理邮件 | 在收件规则中选择条件、填写匹配内容。在自动任务中可以按主题选择具体邮件，也可以设置动态筛选条件。已有复杂条件仍可在高级选项中查看。 |
| 导入、导出和备份 | 从侧栏的“导入与备份”进入相应功能，通过文件或文件夹选择器指定位置。迁移规则时，可从已打开的经典 Outlook 中选择邮箱，也可打开以前导出的规则文件。 |

这次先按收信、回信、找信和配置邮箱的顺序走查，再检查了规则、任务、通知、插件及迁移工具中的名称与输入方式。此前的开发示例占用了主导航，插件启停需要手填标识，草稿和待发邮件的入口也不明显。改版将常用操作放进邮箱侧栏，把管理功能放在可展开的分组中。窄窗口使用下拉导航。点一封邮件后可使用整个窗口阅读，点“返回邮件列表”即可继续选信。

## 验证范围

桌面自动化使用虚构的办公账户和四封本地邮件，其中一封含有附件。所有账户和草稿写入独立的测试目录。此轮没有安排真实用户访谈。QQ、163、个人 Outlook.com 和企业 Exchange 的在线授权、收发和权限验收，沿用任务 000 的集中验收清单。

办公流程自动化检查了从收件箱搜索主题、用可发信的账户回复、草稿往返、原邮件附件列表、插件启停写入配置，以及缩小窗口后阅读和返回列表。对窄窗口额外检查正文的实际高度，并复核了截图。

## 本地验证结果

- 最新代码的非界面检查输出了 75 条通过结果，包含邮件存储、搜索、规则、账户、插件启停和更新检查。
- 使用安装包里解出的应用完成了办公流程。收件、草稿、插件管理和窄窗口截图均来自实际窗口。
- 扩展样本完成了创建账户、在本机回环邮箱收发和移动邮件、导入 EML、离线翻看 Outlook.com 邮件，以及从本地规则清单导入停用规则。直接从已打开的经典 Outlook 读取规则，已用模拟的规则对象检查字段和顺序，真实邮箱的读取留待集中验收。
- 安装包内的 89 个发布文件均与本机构建逐文件核对，校验值一致。验证使用了已有的运行时和工具。

桌面回归覆盖了本地邮件翻页、HTML 阅读、附件保存、四种导出格式、PST 导入、归档、备份恢复、提醒、插件版本切换和 30 轮插件页面加载与关闭。回归中发现，个别第三方窗口关闭后仍占用组件，会妨碍操作其他插件。修复后用实际的自定义窗口插件单独复验，停用设置已写入，插件页面已移除，随后另一个插件仍能正常停用和启用。外部插件的账户权限也已在界面中按邮箱名称勾选，并与保存结果核对。
