## 复验入口与证据

- `./scripts/verify.ps1 -Ui` 通过锁定依赖还原、解决方案构建、样例插件打包、非 UI 检查、win-x64 框架依赖发布和实际启动，再运行默认桌面验收。覆盖重复启停 30 轮、损坏配置恢复、导入导出及正常退出。高级原生控件示例本机返回程序集保留诊断，彻底卸载需要重启。日志在 `artifacts/task000-final-all.log`，桌面输出在 `artifacts/task000-ui-final-20261118`。
- 真实邮件协议使用本机 GreenMail，仅在其专用测试邮箱间收发。`MyMailBox.Checks` 的附加组为 `protocol-live protocol-faults imap-sync imap-conflicts organization-live mail-actions-live transfer-live compose-live send-plan-live task-archive-live task-events-live automatic-mail-live`。套接字故障服务器覆盖部分拒收、连接中断和丢失确认。证据在 `artifacts/task000-final-live.log`。
- `MyMailBox.UiChecks -- protocols` 通过服务器设置、IMAP/SMTP/POP3、统一收信、移动与撤销、跨账户复制、富文本草稿、自动外发批准、后台归档、托盘和键盘流程。实际 192 DPI 下缩至 650×485 DIP 后，键盘可切换导航、聚焦搜索或写信、修正输入并继续工作。输出在 `artifacts/protocol-acceptance/ui-20261118-143146`。
- `MyMailBox.UiChecks -- graph` 验证登录入口、未登录反馈和断开清理，未使用个人账户授权。输出在 `artifacts/graph-acceptance/ui-20261118-143252`。
- 最终性能复测在 10 万封邮箱测得翻页、阅读、搜索首批和取消反馈 p95 分别为 91.54、51.58、1,114.85、10.49 毫秒。滚动帧间隔 p95 为 33.16 毫秒，最长 40.83 毫秒。原始读数在 `artifacts/performance-v1/100000/ui/ui-measure.json`，1 万封组在同级 `10000` 目录。
- 升级验收复用本机运行时和 WebView2，使用仅用于本地隔离环境的临时 Ed25519 签名。证据在 `artifacts/task000-upgrade-results/upgrade-result.txt`。正式发布密钥、Tag 和 GitHub Release 没有用于此轮升级。沙盒、桌面测试进程及本轮启动的 GreenMail 已结束。
