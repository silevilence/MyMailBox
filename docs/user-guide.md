# MyMailBox 使用指南

## 安装和第一次收件

打开软件后会进入收件箱。左侧选择“写邮件”可写一封新邮件；未写完的邮件在“草稿箱”中继续编辑。“已发送”显示本机保存的发件副本，“发件箱”可查看待发送和发送失败的邮件。缩小窗口后，可用上方的下拉列表切换页面。

在 Windows x64 上运行安装包。若安装器提示缺少运行时，按照提示安装 x64 的 .NET 10 运行时，再运行安装包。工作空间默认位于 %LOCALAPPDATA%\MyMailBox。首次使用可先在“本地邮件”导入一封 EML，打开正文和附件，验证离线阅读。

从“设置”打开“邮箱账户”，新建账户，选择与邮箱匹配的提供者并保存。在“收发设置”选择刚建的协议账户，核对收信与发信服务器、端口、加密方式和登录身份，分别保存两端凭据并测试连接。QQ 邮箱与网易 163 的预设会显示本提供者的客户端授权码说明。若授权码已撤销，重新生成后更新用到它的收信和发信配置。

进入“统一收件箱”，选择该账户并刷新。打开一封邮件会按需下载正文。可为各账户单独启用自动收件。IMAP 可先同步摘要，POP3 默认保留服务器副本。在“写邮件与草稿”选定发件身份，保存草稿或发送后，到发件队列核对结果。若提交后失去回执，先核对服务端的已发送邮件，再决定是否重发。

## 连接个人 Outlook.com 或公司 Exchange

个人 Outlook.com 账户在“邮箱账户”创建。打开“Outlook.com 邮件”，选中该账户，点“登录微软账户”并在微软窗口完成只读授权。读取根目录后，选择目录并点“增量同步选中目录的摘要”。在已同步目录中可查看上次成功时间，翻页阅读已缓存的摘要及已保存的原文。断网后仍能翻页。网络恢复时选中原目录，点“继续同步此目录”，可在当前页查看新结果。发信、保存云端草稿和整理邮件需另点“授权发信与整理”。授权过期时，用同一个邮箱身份重新登录。

公司部署如提供 Exchange ActiveSync，可在“邮箱账户”新建对应类型，进入“Exchange 连接”，填写管理员提供的 HTTPS 地址和登录身份。确认服务器支持的协议和命令，根据组织要求决定是否允许本机建立同步关系。写入权限需单独允许。被设备策略阻止时，联系管理员核对准入。在“邮箱文件夹”列目录、阅读或移动邮件。企业部署及其实际允许的操作须由本单位验证。

## 迁移经典 Outlook 账户和规则

在“导入 Outlook 账户”查找本机经典 Outlook 的邮箱配置，选择来源再读取账户。向导显示可读取的 IMAP、POP3、SMTP 字段。核对邮箱地址、服务器、端口和加密方式。对已有账户，先查找同类型同地址的匹配项，选择目标并确认映射。新建账户后，在“收发设置”补录凭据。新 Outlook 或未提供所需字段的来源可在“邮箱账户”手动添加。

再次读取同一份 Outlook 邮箱配置，可看到已确认的来源和剩余账户。来源字段发生变化时，重新预览、核对目标再确认。要迁移规则，请先打开经典 Outlook。在“收件规则”中展开“导入经典 Outlook 规则”，点“查看已打开的 Outlook 邮箱”，选择邮箱并读取规则。也可以选择此前导出的规则文件。核对本地账户和目标文件夹，预览后再导入。导入的规则处于停用状态。逐项核对条件、例外、执行顺序和跳过原因，试运行后再启用。

## 导入 PST、核对结果和续传

在“本地邮箱管理”创建或打开目标邮箱。在“导入邮件文件”选择 PST 和来源文件，再选目标邮箱。支持经典 Outlook 的 ANSI 和 Unicode PST。旧 ANSI 文件缺少编码信息时填写来源代码页，例如简体中文 Windows 常用 936。点“预览目录”核对层级和项目数，再开始导入。

完成后点“查看逐项报告”。报告位于工作空间的 mail\pst-reports，格式为 JSONL，逐项记录已保存、重复、跳过、失败以及正文或附件转换差异。PST 内容由可读属性重建为 MIME，阅读页可核对正文、附件和嵌入邮件。若需要保留原始取证材料，请单独保存来源 PST。

进程退出、磁盘空间不足或导入器停用后，已提交的邮件仍可阅读。恢复空间或启用同版本插件，回到此页选择“未完成的导入”，点“恢复所选导入”，确认后继续。来源发生变化时重新预览并选择目标邮箱。只需导入单封原始 EML 时，也可使用“本地邮箱”的 EML 导入入口。

## 自动归档和失败后继续

打开“邮件自动化”，新建任务，设置作用账户或目录及筛选条件。先“预览目标集合”，再设置归档目的地、时间范围和触发时间。在“动作、时间与执行记录”中点“预演本次归档”，核对样本、目标及预计数量后保存任务。需要实际执行时，点“立即执行已保存任务”，或启用计划后保持应用运行。应用退出期间无法执行收件和任务。

在“最近执行”选择对应批次，刷新历史，查看成功、跳过和待处理的项目。失败时先排除磁盘空间、目录映射、插件停用或权限问题，再点“继续或重试”。对会删除来源、自动外发或已有不确定回执的操作，按页面提示核对执行记录和目标副本后处理。

## 备份、搬迁和插件

要恢复整个工作空间，在“工作空间备份”指定新备份文件并点“创建一致性备份”。恢复时选择已有备份和一个尚不存在的新目录，点“校验并恢复到新目录”，再在新窗口打开恢复工作空间。恢复后的在线账户需重新授权。若仅需搬运一批邮件，使用“邮件归档包”导出所选范围，在目标工作空间校验并导入为独立本地邮箱。

“配置模板迁移”用于搬运账户说明、规则、搜索、自动化以及普通插件配置。在目标工作空间先预览，按稳定身份明确选择账户和目录。核对冲突后应用，检查恢复的规则与任务，再按需启用。凭据和插件权限需在目标工作空间重新设置。

打开“设置”里的“插件管理”，从列表选中插件，也可按名称查找，点击“启用”或“停用”。申请权限的插件会列出可勾选的项目。要安装新插件，展开“安装插件”，选择 ZIP 文件，核对来源和权限后安装。已安装的其他版本也在列表中，选中版本即可切换。若插件正在处理邮件，请等待当前操作结束。核心插件配置位于 profiles\default\core.json，修改后重启。启动修复页可备份并恢复默认核心配置。开发与贡献入口在仓库 README 的“使用与开发指南”中。

## 更新和故障恢复

在“软件更新”核对当前版本、更新源、通道，保存设置后点“立即检查”。查看版本说明再点“下载并校验”。若提示未配置签名或校验失败，保留当前安装并检查更新来源。点“安装更新并退出”后，应用保存草稿、等待关键任务并准备独立备份。保持工作空间可写并留足磁盘空间。

更新后检查工作空间、草稿和待处理任务。如升级中断或新版本无法打开，查看工作空间的 updates\upgrade-state.json 和 logs。状态记录可定位升级阶段、诊断和独立备份。在可运行的兼容版本中用“工作空间备份”将该备份恢复到新目录，先核对数据再继续使用。若本地邮件或索引异常，也可在“存储与恢复”检查原文与索引。
